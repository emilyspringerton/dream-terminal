# TRAPX v1 (Terminal Prototype)

Run:

```
go run main.go
```

**Overview**
* Single-neighborhood systemic simulation on a 12×12 grid.
* Fixed-tick simulation (2 seconds) continues without pausing.
* Player interventions happen via five operation cards placed by typing commands: `<card> <x> <y>`.

**Card List**
1. Outreach
2. Investment
3. Enforcement
4. Logistics
5. Suppression

**Required Language**

Progression systems in TRAPX are experimental and evolving.

The current version focuses on systemic simulation and indirect control. Interfaces, progression models, and long-term structures may change as the simulation matures.

No roadmap promises are implied.

**Final Lock Statement**

TRAPX v1 is frozen as a single-neighborhood systemic simulation with a card-based intervention interface.

Anything not explicitly listed above is out of scope.

TRAPX factions are fictional systems inspired by historical dynamics. They do not represent real ethnic, religious, or cultural groups.
